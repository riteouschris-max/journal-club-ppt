# 继续与局部修改

| 用户请求 | 默认允许 | 默认锁定 |
|---|---|---|
| 字号、对齐、小修 | 字体、几何、留白、删重复提示 | 页序、panel 分组、科学内容、保留页 |
| 图文再平衡、解释增加 | 同页布局、解释措辞、补充解读 | 页数、页序、核心结论、原图、保留页 |
| 改某结果解释 | 指定页内容，回看相关来源 | 其他页及已接受视觉 |
| 重新拆分、压缩全套 | 明确授权的结构范围 | 数据真实性及来源 |

最新用户指令优先，本表不是新增确认关卡。用户说“封面别动”时不改其字体、题目、日期或构图。

1. 核对实际路径与哈希，避免同名旧稿混用。有源文件就修改源。找不到 `(1)` 文件时先查任务目录及已知附件位置，不扫描全盘。
2. 读取状态、主题、逐页内容和最近检查。不从聊天重新推导所有结论，不读取无关 Figure。
3. 新模板项目先 `audit.py --snapshot`，保存页序、结论、图源和锁定页。已有项目用原有 manifest 与检查程序。
4. `render_deck.py changes` 列出受影响页；`build --pages changed` 生成单独预览。完整交付只用不带筛选的 `build`。
5. 全套做轻量机器检查，查看受影响页及邻页；全局主题变化需检查全部。旧报告 PASS 不能代替当前版本检查。
6. 完整导出，记录实际输出 SHA256、页数、已查看的渲染页。PDF 不可用时不能声称已交付。

状态记录输入哈希、当前源文件、已完成项、待办和下一明确动作。恢复时复用哈希一致的资产。

skill 不自带后台计时器。只有用户要求且平台支持时才配置自动续跑；否则保留检查点，准确说明可从此处继续。
